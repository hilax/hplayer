# HPlayer 界面规范（3.0 · 放映厅）

所有页面的颜色、字号、间距、圆角、图标、动效都从下面几处取值，页面里不再自己写颜色值、字号数字、圆角数字、图标名字和动画参数。改规范就是改全应用。

**视觉规则的权威版本在仓库根目录 [`.interface-design/system.md`](../.interface-design/system.md)**（颜色 token、字号阶梯、间距、圆角、表面层级、交互状态、组件规格）。本文件只记录页面结构和各模块的行为。

| 要改什么 | 改哪里 |
|---|---|
| 颜色、间距（`Theme.Space`）、圆角（`Theme.Radius`）、字号（`Theme.Typo`） | `Views/Theme.swift` |
| 图标 | `Views/Icons.swift`（`AppIcon`） |
| 动画、触感、按压手感 | `Views/Motion.swift` |
| 按钮、输入框、行、分组、筛选胶囊、角标等通用控件 | `Views/DesignComponents.swift` |
| 底部标签栏与公共导航路径 | `Views/AppTabBar.swift`、`Views/HomeView.swift` |

## 配色（3.0 · 放映厅）摘要

- 石墨灰阶打底（深色 `#0A0A0B`、浅色 `#F7F7F8`），卡片、弹层、控件按明度逐级抬高。
- 主操作色是白 / 墨（深色模式白底墨字），每屏只有一个。
- 唯一的彩色是琥珀（深色 `#E6A54B` / 浅色 `#8A6008`）：观看进度、「更新、在看、进行中」、焦点、评分。
- 卡片靠底色深浅和细线分层，不用投影；只有浮层在浅色模式下带一层轻投影。不再用渐变做装饰（棱镜五色只留给品牌标志和弹幕取色）。
- 只用系统字体，全部跟随系统字号，最小 11pt，字重最多 bold；层级靠字重和颜色。
- 主按钮、筛选块是胶囊；次按钮、输入框是 10pt 圆角矩形；浮在画面上的玻璃控件保持胶囊。

## 图标

1. 只用 SF Symbols 的**线框款**，字重统一 `Theme.iconWeight`（medium）。
2. **实心款只留给"正在发生 / 被选中"**：播放键、评分星、选中的底部标签、勾选圆圈。
3. **一个意思一个图标**：所有提醒是 `alert`，所有"更多"是 `more`，所有"完成"是 `success`，所有"关闭"是 `close`。
4. 页面里不写 `"xxx.fill"` 这样的字面量，一律 `AppIcon.xxx.name`。需要新图标就在 `Icons.swift` 加一个 case。
5. `ios-native/scripts/check-icons.py` 会在云端构建的第一步检查这条规则，违反就直接失败。
6. 列表行、设置行的图标不垫底色：19pt 线框图标直接放在行首（`LibraryActionRow` / `RowIcon`，24pt 宽一列，主文字色），分隔线从标题处开始（`LibraryActionRow.dividerInset`）。「我的」「网盘」的列表只写标题，不加解释性的副标题和脚注；右边放数量，有更新、在下载时用强调色（朱砂）。

## 动效

1. **只用弹簧**：`Motion.snappy`（点按、选中）、`Motion.smooth`（面板、内容切换）、`Motion.bouncy`（勾选标记）。淡入淡出用 `Motion.fade`。
2. **不做无限循环动画**：循环动画会让自动化测试永远等不到界面空闲，也费电。唯一的例外是顶部轮播的自动翻页（`LoopingCarousel`）：它不是一直在动的动画，而是每 4 秒翻一页，而且只在用户看得见、没在碰的时候翻——打开「减少动态效果」、手指在轮播上、轮播滑出屏幕、切到别的页面或 App 进后台时都停；界面截图和首页 UI 测试默认关掉（`HPLAYER_CAROUSEL_AUTOPLAY=1` 打开）。
3. **打开"减少动态效果"时**，位移和缩放全部变成瞬间完成，只保留颜色变化。
4. 常用效果：
   - 按压：`.buttonStyle(.pressable)`，按下缩小并压暗，松手弹回。
   - 货架、网格、列表里的卡片依次浮现：`.reveal(index, id: 卡片id)`。这些容器会回收滑出屏幕的卡片，浮现记录放在 `RevealLedger`（视图外面），所以只有一组卡片刚出现的头半秒（第一屏）会播放浮现，滑回来或滑进来的卡片直接显示，快速滑动时不会出现格子消失又冒出来。固定的几块内容（不在懒加载容器里）才用不带 `id` 的 `.reveal(index)`。
   - 标签栏、筛选胶囊的选中底座在选项之间滑动（`matchedGeometryEffect`）。
   - 数字变化逐位滚动：`.rollingNumber()`；播放⇄暂停图标变形：`.morphSymbol()`；选中时图标弹一下：`.bounceSymbol(on:)`。
   - 勾选圆圈 `CheckBadge`、环形进度 `ProgressRing`。
   - 触感：`Haptics.tap()` / `select()` / `success()` / `warning()`。

## 页面结构

底部四个标签：**首页 / 磁力 / 网盘 / 我的**（2.0：片库并入首页频道，磁力升为一级标签），标签栏用系统原生 TabView：iOS 26 上是悬浮在屏幕底部的横向圆角 Liquid Glass 胶囊（页面内容从下面滚过、可左右拖动切换），较低版本是系统标准标签栏；选中色用主文字色（深色模式为白），图标用统一图标表。公共 NavigationStack 的根页面是整个 TabView，各标签页不再各自建立导航栈。进入二级页面时整体盖住标签页和胶囊栏，返回按钮及侧滑都让两者随同一页面一起回来，不再单独切换系统标签栏显隐。网盘的目录路径通过 HomeNavigation 接入公共导航，保留面包屑跳转。搜索是从各页右上角进入的全屏页，不占标签位。返回时搜索页先淡出（0.18 秒），完全看不见之后才收键盘：键盘收起的那一帧系统会把搜索页内容往下推一截再弹回，先淡出就看不到这一下；底下的页面和标签栏不跟键盘变化，始终不动。

- 首页频道和磁力分类都是「固定头部 + 左右滑动分页」（`PagedHeaderContainer`，`ChannelPager.swift`）：内容是横向分页 ScrollView（iOS 16 退回系统分页 TabView），左右滑就切换频道 / 分类（页里的横滑货架、轮播优先接手指，从空白处滑才翻页），点频道条也会翻过去。头部两行盖在分页上面：往上滚的前 54pt 第一行（频道条 / 分类条）跟着上移并淡出，搜索框滑到状态栏下方后固定，铺上页面底色和一条细线，下面的内容继续滚。每一页各记各的滚动位置，换页时头部按那一页显示。新页面要在内容最上面留 `channelPageInsets.top`，纵向 ScrollView 加 `.pageScrollContainer()`（iOS 18+ 用 `onScrollGeometryChange` 读滚动距离），内容加 `.tracksPageScroll()`（iOS 17 及更早用）。页面只在去过或和当前页相邻时才建。
- 首页：推荐、动漫、片库、短剧四个频道共用一个头部：第一行左边频道条「推荐 / 动漫 / 片库 / 短剧」（`HomeChannelBar`，选中项下方 18×3 光轨），推荐频道右边只有「添加」（观看历史从「继续观看」的「全部」进，顶栏不重复放）；第二行搜索框（`ChannelSearchField`，点进全局搜索，右侧「筛选」：推荐去片库频道、片库滚到筛选区；动漫不放）；头部下面各页自己的轮播（`AmbientHeroSection`，氛围色从屏幕顶端铺起，头部没收起时透出来）。推荐频道从上到下：轮播 → 继续观看（168pt 横卡）→ 我的追番 → 热门新番 → 我的片库 · 电影 → 剧集 → 最新更新 → 演员合集。
  - 轮播（`LoopingCarousel`）：左右留 16pt 的 16:9 圆角卡片，片库精选和动漫接口的热播横图（`/app/banners`，约 1700×920）交替放，最多 8 张。翻页照参考视频：**卡片和图都不动**，下一张图从卡片右侧正中以一道向左鼓的弧形边（`ArcReveal`，圆心在卡片右边外侧、上下居中）揭出来，往左扫过整张卡片；片名、信息、按钮在揭到一半时**原地直接换**成下一张的（不滑动、不淡入，和参考视频一样一帧换掉）。手动拖时弧线跟着手指走，松手吸到最近一张；每 4 秒自动翻一张；首尾相接（首尾各放一张复制页，停稳后无动画换回真页，见 `HeroLoop`）。分三层：画面层（`HomeSlideArtwork`：图、暗色渐变、右上角强调色「精选」/「热播」角标）、透明手势层（iOS 18 起是按页吸附的横向滚动视图，滚动位置换算成揭开进度；单击片库影片直接播放、单击热播动漫进详情；长按片库影片弹出菜单：播放、匹配封面、不在精选中显示（仅推荐频道）、更多选项）、文字层（`HomeSlideCaption`：白字片名和信息，卡片上不放按钮）。右下角胶囊指示点跟着文字换。片库影片只有竖海报时不硬裁：铺一层海报虚化，海报本身立在右边。
  - 顶部氛围色：当前这张轮播图的取色（画面平均色，明度、饱和度封顶），从屏幕顶端往下淡进页面底色，翻页时 0.6 秒交叉淡入；浅色模式用同色相的淡色（`ArtworkTint.pastel`）。页面本身跟随系统深浅色。实现见 `Views/HomeAmbientTint.swift`。
  - 热门新番：动漫接口按播放量（`sort=hits`）的前六部，三列竖版海报（接口只有竖图 `pic`）；右上角状态角标（强调色「更新」/ 灰「完结」），右下角集数，片名右侧「⋮」更多（加入/取消追番、复制片名），前三名的副标题是强调色「最多播放第 N 名」，其余是类型。「⋮」只放在这一处。
  - 我的片库 · 电影：两列 16:9 横卡，先放四部，「全部」进完整海报墙。横图用 `backgroundURL`（只有 Cinemeta / TMDB 匹配到的才有）；DMM / R18 的横版封套直接铺；只有竖海报的铺虚化底、海报立在中间。右上角评分。
- 首页 · 动漫频道（`AnimeCatalogView`）：顶部同上（搜索「搜索动漫」，轮播是动漫接口的热播横图；轮播位置一直留着，数据没到时是灰色占位，到了直接填进去，页面不跳）。下面一排圆形快捷入口（`ChannelShortcut`：最新上架 / 最多播放 / 我的追番 / 剧场版（接口有这个频道才放）），再下面是热门新番（和首页同款三列竖海报，`sort=hits` 前六部）+ 各频道货架（18pt 标题、右侧「全部 ›」、108pt 海报横滑）。不再有频道胶囊：频道的「全部」、快捷入口、热门新番的「更多」（首页、动漫频道都是）一律推进新的列表页 `AnimeBrowseView`（导航栏标题 + 排序胶囊最新上架 / 最多播放 + 至少三列海报网格，滑到底翻页；接口的 weight 与 addtime 实测顺序相同，所以用 hits）。数据放在 App 级的 `AnimeHomeStore`（频道和货架）和 `HomeOnlineFeed`（轮播、热门新番），切频道再回来直接显示，十分钟内不重复拉；轮播取色存在共用的 `HeroPalette.shared` 里。封面从网络取回时用 `ArtworkReveal`：0.5 秒淡入并从 1.06 倍落回原尺寸，底色等图显出来后再撤，缓存命中直接显示；减弱动态效果时只淡入。
- 动漫详情页（`AnimeDetailView`）：封面虚化大图抬头（左上返回、右上追番爱心）→ 海报 + 片名、连载、年份 / 地区 / 评分、类型胶囊 → 一行数据「播放量 · 评论数 · 弹幕数」→ 简介（3 行，更多 / 收起）→ 主按钮（播放 / 续播第 N 集 · 看到 mm:ss）→ 选集 → 评论预览。选集只占一行：标题右边写「国语 · 更新至 166 集」和「全部 ›」，多条线路时下面一行线路胶囊，再下面一行横滑的选集格子（`AnimeEpisodeCell`，打开时滚到在看的那一集）；「全部」在选集栏里原地展开成五列网格（`AnimeEpisodePanel`），超过 50 集按「1-50 / 51-100…」分段（默认停在在看的那一段），标题行换成正序 / 倒序切换和「收起」，点一集就播。展开、收起都是直接换（不做淡入和位移动画），高网格不会和下面的评论区叠在一起。评论预览取置顶和热评的前三条（`AnimeCommentRow`），「全部 ›」推进整页评论 `AnimeCommentsPage`（最热 / 最新、可翻页）。
- 首页 · 片库频道（`CatalogTab`）：顶部同上（搜索「搜索片库」，轮播是最近加入的电影，有横版背景图的排前面，最多 6 张；单击播放，长按播放 / 匹配封面），下面一排类型快捷入口（全部 / 电影 / 剧集 / 动画 / 演员），一行下拉筛选胶囊（`FilterMenuChip`：地区、年份、排序，选了非默认值的实心；右边是总数），再下面是至少三列的海报网格。
- 首页 · 短剧频道（`DramaTab`）：「短剧 / 漫剧」两个胶囊切换 + 三列 2:3 海报网格（左下角集数角标），滑到底自动翻页、下拉刷新。详情页是封面抬头 + 主按钮（播放第 1 集 / 继续看第 N 集）+ 简介 + 数字选集格子（当前集白底、看过的带光轨进度）。封面是密文，取回后本机解密（`DramaCoverStore`）；播放地址每集现取。只按这两个分类拉列表，站点的换脸类内容不接入。
- 网盘：34pt 大标题（滚出后顶部换成紧凑标题栏）→ 账号条（名字、连接状态、4pt 琥珀容量条）→ 一张卡片里的四格快捷入口（传输中心 / 离线下载 / 本机视频 / 回收站）→「全部文件」和根目录文件列表（不画分隔线）。未登录时是登录卡片 +「不用登录也能用」两行。
- 传输中心（网盘 / 我的 → 传输中心）：顶部三格「云端进行中 / 本机下载中 / 边下边播记录」（各带来源色圆点：115 蓝、本机绿、磁力紫）→ 三组入口，每组下面列最多三条进行中任务的光轨进度 → 底部一段说明三种下载的区别。
- 磁力（一级标签）：和首页频道同一套固定头部 + 分页，「最新 / 专题 / 女优 / 最热」左右滑动切换，每个分类各自加载、各自保留数据。搜索结果和链接解析盖在分页上面（这时不能左右滑）。第一行左边是分类「最新 / 专题 / 女优 / 最热」（`MagnetCategoryTabs`，样子和 `HomeChannelBar` 一样：选中 20pt 加粗 + 18×3 棱镜光轨），右边「粘贴链接播放」和「镜像域名」两个图标；第二行是胶囊搜索框（`MagnetSearchField`，可直接输入，键盘「搜索」键提交；为空时右侧是系统粘贴按钮，不弹粘贴授权，也不主动读剪贴板）。输入框认出磁力链接、40 位 / Base32 信息哈希或迅雷链接时不去站点搜索，下方直接出解析面板（`MagnetLinkPanel`：资源名、短哈希、Tracker 数，「在线播放」「存到 115」「复制」）。不在搜索、没贴链接时，下面是「最新上架」轮播（前 6 部的 JavBus 大封面，`HomeSlide.magnet`，和首页同一个弧形揭开翻页、顶部氛围色；点进磁力详情；加载时留出灰色占位）。再往下是内容区，栏目标题和首页货架一样 18pt 粗体（`MagnetSectionHeader`）。正在看搜索结果时点分类会先退出搜索。
  - 最新：「最新上架」标题 + 三列 3:4 海报网格，番号浮在封面左上角，下面是 13pt 两行标题和 11pt「女优 · 发行日期」，滑到底自动翻页。
  - 专题：五家片商的宽卡片（缩写方块、名称、常见番号前缀、淡淡的名称水印）。
  - 女优：三列圆头像加姓名，按人气排序，滑到底翻页。
  - 最热：顶部一条口径说明（站点没有月榜，取人气女优近 30 天主演新作），下面是带序号的影片行（前三名序号强调色；15pt 番号、13pt 灰色标题、强调色女优名），不翻页。
  - 搜索结果：横向的「匹配女优」卡片 + 「相关影片」影片行。
  - 下钻页（使用公共导航栈，左上角返回上一层）：女优页（头像抬头 + 「主演作品 / 全部参演」切换 + 海报网格）、片商页（片商抬头 + 海报网格）、磁力详情页（封面抬头、参演女优胶囊、磁力资源卡片：中文字幕白底黑字、高清描边，一行「115 云下载播放」主按钮 +「存到 115」+ 复制图标）。「存到 115」统一走 `Offline115Saver`，和离线下载页用同一个保存目录。播放页盖在详情页上，关掉仍停在详情页。
  - 状态统一：加载中用占位块，出错给「重新加载」和「更换镜像域名」，为空用图标加一句话。组件都在 `Views/MagnetBrowseKit.swift`。
- 媒体库管理（我的 → 媒体库管理，全屏二级页）：顶部一张扫描主卡片（进度环、状态、扫描范围、三项进度、主操作与「选择文件夹扫描」）→ 片库概况（匹配进度条 + 片库视频 / 已匹配 / 未匹配）→ 「封面与资料」分组（自动匹配开关、未匹配影片、资料来源、重新匹配）→ 演员资料（开启番号匹配后）→ 「维护」分组（刷新、复制诊断、清空继续观看）。
- 我的：34pt 大标题（滚出后顶部换成紧凑标题栏）→ 账号卡片（头像、名字、连接状态、切换 / 退出）和统计（视频、观看记录、追番）→「我的内容」（我的追番、传输中心）→「播放」（自动连播、回到桌面时自动小窗、字幕样式、边播边存、解码方式）→「弹幕」（显示弹幕、可展开的弹幕样式：实时预览 + 区域、不透明度、字号、速度）→ 外观 / 媒体库 / 关于。行之间不画分隔线。
- 播放器：竖屏是顶部 16:9 小窗（返回、截图、更多、播放、进度、全屏）+ 下方信息页（片名、清晰度/倍速/字幕/画面/解码快捷格、选集横条、接下来、文件信息）；在线动漫的信息页上方多一行「简介 | 评论」（光轨下划线）和弹幕开关「弹」、弹幕设置；评论页是置顶 / 热评徽章 + 最热 / 最新切换 + 分页加载。弹幕画在视频层上（`DanmakuOverlay`，Canvas 逐帧绘制、带阴影、同速轨道不追尾），横屏控制条倍速键旁也有「弹」开关；区域、不透明度、字号、速度在弹幕设置面板里调。点全屏转横屏，画面铺满，右侧面板分「选集 / 倍速 / 清晰度 / 字幕音轨」四页，选集页带自动连播开关。默认直接横屏播放，点退出全屏键回到竖屏小窗。播放器放在独立的 UIWindow 里（`PlayerWindow`）：主窗口只支持竖屏，播放器窗口才真的横屏，所以控制中心、录屏、系统弹窗方向和旋转锁定都按真实横屏走，其他页面一直是竖屏；关闭时播放页柔和淡出并轻轻缩小后移除窗口，没有翻转，也不用遮罩。所有打开播放器的地方统一用 `.playerWindow(...)`，不要再用 `fullScreenCover`。
- 进入详情、全部网格、演员合集、网盘目录、设置子页等二级页面时，整个标签根页面被覆盖；返回标签根页面时一起露出内容和标签栏。

## 新增页面时

1. 用 `DesignPage` / `ScreenTitleBar` / `DesignGroup` / `LibraryActionRow` / `PrimaryActionStyle` 搭，不要自己写背景和字号。
2. 图标只从 `AppIcon` 取；弹层右上角用 `SheetCloseButton`。
3. 列表和网格里的卡片加 `.reveal(index, id: 卡片id)`（一定要带 id），可点的东西加 `.buttonStyle(.pressable)`。
4. 二级页面通过公共导航栈进入，不要另外切换标签栏显隐；页面根视图加 `.designScreen("名字")`，并在 `docs/prototype-coverage.json` 和 `ScreenCatalogUITests` 里登记。

## 网盘文件管理

- 目录页：面包屑 + 「N 项 · 几个文件夹，几个视频」+ 排序入口（名称 / 大小 / 日期，可反向，文件夹置顶可关）。右上角「⋯」菜单：新建文件夹、选择、排序方式、传输中心、回收站、显示全部文件类型、把此文件夹加入首页、刷新。
- 多选：顶栏「全选 / 全不选」、居中的「已选 N 项」、右侧「完成」；底部浮动操作栏（`FileActionDock`）依次是移动、复制、重命名（仅单选）、信息（仅单选）、下载、加入首页、删除（红色）。选中行底色用 `Theme.tileTint`，行首是 `CheckBadge`。
- 弹层：删除确认用居中卡片（红色图标、被删项目清单、「同时从 HPlayer 资料库移除」开关、红色「移入回收站」主按钮）；移动 / 复制是大号底部面板（移动到 / 复制到分段切换、逐级浏览的文件夹列表、被选中的文件夹灰显并写「已选中，不可作为目标」、底部显示目标位置）；文件信息是带标题、徽章和键值卡片的底部页面。
- 二级页面：回收站（提示条、选中项底部「彻底删除 / 还原」）、离线下载（进行中 / 已完成 / 失败 分段、任务卡片带进度条、速度和剩余时间、底部「清除已完成」「添加任务」）、下载管理（下载中 / 已完成 分段、存储占用卡片、暂停 / 继续 / 重试圆形按钮、已完成显示「播放」或「导出」）。进度条是 6 pt 的光轨渐变，暂停时变灰。
- 危险操作统一用 `DestructiveActionStyle`（红色胶囊 + 白字）；操作进行中用 `OperationOverlay` 挡住重复点击，完成后用底部轻提示。

## 应用图标

- 选择态唯一来源是 `Services/AppIconStore.swift`：点按当帧乐观更新勾选并持久化到 `hplayer.home_icon_choice`；系统 `alternateIconName` 只做延迟校准（切换后 2 秒内不回读覆盖），失败回滚到切换前的选择。不再依赖异步回调或 scenePhase 的即时系统回读，避免「桌面已换、页内勾选不动」。
- 确认提示用页内底部玻璃卡片 `IconChangeNoticeCard`（新图标预览 + 勾选角标 + 「图标已更新 / 主屏幕已同步为…」+ 撤销 + 关闭），4.5 秒自动收起；失败同卡片红色态。不再使用系统 `.alert` 承载成功提示。
- 换图标优先走不弹系统确认框的静默接口（`_setAlternateIconName:completionHandler:`，运行时 `responds(to:)` 校验）；签名不存在时回退公开 `setAlternateIconName`，此时系统仍会弹自己的提示，页内卡片在其后出现。模拟器 `HPLAYER_HOME_TEST=1` 不触碰 SpringBoard，读写 `hplayer.simulated_alternate_icon`。


## 图片加载与预取（Nuke）

- 所有网络图片走 `ImagePipeline`（底层 Nuke 13）：下载合并、限流、优先级排队、内存（160 MB）+ 磁盘（400 MB，沿用 `Caches/HPlayerImages` 和原文件名）两级缓存，ImageIO 直接出缩略图并在后台解码。
- 业务规则留在 `ImagePipeline` 这一层：按图床加请求头、拦截 200 错误页、临时错误重试两次、解不出图的缓存自动删掉。
- 不能直接下载的图（短剧封面要先解密）用 `image(id:maxPixel:load:)` 接进同一套缓存。
- 列表和货架用 `.prefetchArtwork(after:in:count:maxPixel:address:)`：卡片出现时低优先级取后面几张（网格三行、货架四张），最多两路并发、队列上限 36，不抢屏幕上的封面。`maxPixel` 必须和显示时一致。

## 操作反馈与滚动动效

- 关键操作用 `.successPop(_:particle:tint:)` / `.failureShake(_:)`（Pow）：只在状态变成成功 / 失败的那一刻触发；减弱动态效果时关闭。已用于追番、存到 115、复制链接。
- iOS 17 起：横滑货架用 `.shelfContent()` + `.shelfScrolling()` 按卡片吸附，卡片加 `.shelfCard()`（边缘略缩小变淡）；网格卡片加 `.gridCardEntrance()`（从底部浮起）；轮播的手势层在 iOS 18 起是按页吸附的透明滚动视图（能拿到滚动位置和阶段：拖动时弧形揭开跟手，手指在上面时暂停自动翻页，停在两页中间会吸到最近一整页）；更早的系统用分页 TabView，翻完一页后补放揭开动画。轮播卡片里的封面一律用 `Color.clear.overlay { 图.scaledToFill() }.clipped()`，不能写 `.scaledToFill().frame(maxWidth: .infinity, maxHeight: .infinity)`——比例不是 16:9 的图会把整页撑大，片名和按钮被挤出卡片、翻页对不齐。iOS 16 的货架、网格保持原样。

## 短剧竖屏播放器（DramaFeedView）

- 从短剧详情页播放时打开，独立播放窗口以竖屏弹出（`.playerWindow(item:landscape: false)`）。
- 上滑下一集、下滑上一集（自绘翻页，iOS 16/17 一致）；第一集 / 最后一集再拉只有橡皮筋回弹和提示。播完自动翻到下一集。
- 每集一个 AVPlayer，同时只留当前集和前后各一集；前后两集提前缓冲，翻页立即出画面。
- 竖屏视频等比铺满（resizeAspectFill）；横屏视频居中完整显示，下方「全屏观看」在同一播放器里转横屏（`PlayerWindowController.setLandscape`），横屏页有返回、播放、进度和退出全屏。
- 单击暂停 / 播放，长按 2 倍速（松手恢复），底部细进度条可拖动（拖动时加粗并显示时间）；右侧「选集」（半屏面板）和「倍速」（1 / 1.25 / 1.5 / 2 循环）。
- 续播位置、「继续看第 N 集」沿用 RecentStore 和 DramaEpisodeRef。
