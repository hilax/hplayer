# HPlayer 界面规范（2.0 · Prism Noir）

所有页面的颜色、图标、动效都从下面几处取值，页面里不再自己写颜色值、图标名字和动画参数。改规范就是改全应用。

| 要改什么 | 改哪里 |
|---|---|
| 颜色、圆角、字号字重 | `Views/Theme.swift` |
| 图标 | `Views/Icons.swift`（`AppIcon`） |
| 动画、触感、按压手感 | `Views/Motion.swift` |
| 标题行、分组、按钮、筛选胶囊等通用控件 | `Views/DesignComponents.swift` |
| 底部标签栏与二级页面隐藏标签栏 | `Views/AppTabBar.swift` |

## 配色（2.0 · Prism Noir）

从 Prism 应用图标提取：近黑底承载内容，主操作色（深色模式为白）是每屏唯一的主按钮，玫红标出「在看、更新、我的」，棱镜渐变（光轨）只用在进度条、选中指示、发送与解析中。浅色是同一套色相的冷白版本，全部用 `UIColor.adaptive` 随系统切换；播放页、首页精选区始终深色。完整原型与规范见设计画布「HPlayer 2.0 高保真原型与设计系统」。

| 用途 | 深色 | 浅色 | 代码 |
|---|---|---|---|
| 页面底 | `#07080B` | `#F4F5F8` | `Theme.pageBackground` |
| 卡片 / 行 | `#111319` | 白 | `Theme.surface` |
| 抬高一层（弹层） | `#181B23` | `#EBEDF2` | `Theme.surfaceRaised` |
| 控件底 | `#22262F` | `#E1E4EB` | `Theme.surfaceHigh` |
| 主操作色（主按钮、当前集、选中胶囊、实心角标） | `#F5F6F8` | `#111318` | `Theme.gold` / `Theme.primaryAction` |
| 主操作色上的文字 | `#07080B` | 白 | `Theme.onPrimary` |
| 强调（玫红文字、图标） | `#FF4D8D` | `#C42560` | `Theme.accent` |
| 强调实心（压白字） | `#D92B6B` | 同左 | `Theme.accentFill` |
| 光轨 | `#35D0FF → #5B7CFF → #A45CFF → #FF4D8D → #FF8A5C` | 同左 | `Theme.prismGradient` / `Theme.accentGradient` |
| 评分 | `#FFB547` | `#B26A00` | `Theme.rating` |
| 来源色点 | 在线 `#FF4D8D` · 115 `#4C8DFF` · 磁力 `#9A84FF` · 本地 `#33D6A6` | 同左 | `Theme.Source` |
| 正文 / 次要 / 三级文字 | `#F5F6F8` / `#A9AFBC` / `#828999` | `#111318` / `#4D5363` / `#626877` | `textPrimary / textSecondary / textTertiary` |

规则：

- 主操作色上只放 `onPrimary`；每屏只有一个主操作色按钮，其余用表面或玻璃按钮。
- 玫红只做强调（更新、在看、置顶、链接），不做大面积底色；光轨不铺背景。
- 评分一律琥珀星标 + 数字。
- 圆角：海报 10、小块 12、卡片 16、底部面板 28（`Theme.Radius`），按钮与胶囊全圆。
- 片名和大标题用 `Font.display(_:)`（系统黑体最粗一档，2.0 起不再用衬线），其余用系统字体；时间、集数用等宽数字。
- 文字对比度按 WCAG AA：正文 ≥ 4.5:1。

## 图标

1. 只用 SF Symbols 的**线框款**，字重统一 `Theme.iconWeight`（medium）。
2. **实心款只留给"正在发生 / 被选中"**：播放键、评分星、选中的底部标签、勾选圆圈。
3. **一个意思一个图标**：所有提醒是 `alert`，所有"更多"是 `more`，所有"完成"是 `success`，所有"关闭"是 `close`。
4. 页面里不写 `"xxx.fill"` 这样的字面量，一律 `AppIcon.xxx.name`。需要新图标就在 `Icons.swift` 加一个 case。
5. `ios-native/scripts/check-icons.py` 会在云端构建的第一步检查这条规则，违反就直接失败。
6. 列表行、工具卡、设置行的图标统一放在 `IconTile`（中性淡底圆角方块 + 主文字色线框图标）里。

## 动效

1. **只用弹簧**：`Motion.snappy`（点按、选中）、`Motion.smooth`（面板、内容切换）、`Motion.bouncy`（勾选标记）。淡入淡出用 `Motion.fade`。
2. **不做无限循环**：循环动画会让自动化测试永远等不到界面空闲，也费电。
3. **打开"减少动态效果"时**，位移和缩放全部变成瞬间完成，只保留颜色变化。
4. 常用效果：
   - 按压：`.buttonStyle(.pressable)`，按下缩小并压暗，松手弹回。
   - 货架、网格、列表里的卡片依次浮现：`.reveal(index, id: 卡片id)`。这些容器会回收滑出屏幕的卡片，浮现记录放在 `RevealLedger`（视图外面），所以只有一组卡片刚出现的头半秒（第一屏）会播放浮现，滑回来或滑进来的卡片直接显示，快速滑动时不会出现格子消失又冒出来。固定的几块内容（不在懒加载容器里）才用不带 `id` 的 `.reveal(index)`。
   - 标签栏、筛选胶囊的选中底座在选项之间滑动（`matchedGeometryEffect`）。
   - 数字变化逐位滚动：`.rollingNumber()`；播放⇄暂停图标变形：`.morphSymbol()`；选中时图标弹一下：`.bounceSymbol(on:)`。
   - 勾选圆圈 `CheckBadge`、环形进度 `ProgressRing`。
   - 触感：`Haptics.tap()` / `select()` / `success()` / `warning()`。

## 页面结构

底部四个标签：**首页 / 磁力 / 网盘 / 我的**（2.0：片库并入首页频道，磁力升为一级标签），标签栏用系统原生 TabView：iOS 26 上是悬浮在屏幕底部的横向圆角 Liquid Glass 胶囊（页面内容从下面滚过、可左右拖动切换），较低版本是系统标准标签栏；选中色用主文字色（深色模式为白），图标用统一图标表。进入二级页面时用 `.hidesTabBar()`（系统的 `toolbar(.hidden, for: .tabBar)`）收起标签栏。搜索是从各页右上角进入的全屏页，不占标签位。返回时搜索页先淡出（0.18 秒），完全看不见之后才收键盘：键盘收起的那一帧系统会把搜索页内容往下推一截再弹回，先淡出就看不到这一下；底下的页面和标签栏不跟键盘变化，始终不动。

- 首页：左上角频道条「推荐 / 片库 / 动漫 / 短剧」（`HomeChannelBar`，选中项下方 18×3 光轨），右上角圆形按钮。推荐频道：精选轮播 → 继续观看 → 我的追番（有新集带「更新」角标）→ 在线 · 热门新番 → 在线 · 最新更新 → 电影 / 剧集 / 演员合集货架。
  - 翻页时图片停在原地，页面边缘像一扇窗从图上扫过去，片名跟着页面走（减少动态效果时改为普通平移）。
  - 首尾相接循环：第一张往右滑是最后一张，最后一张往左滑回到第一张（首尾各放一张复制页，停稳后无动画换回真页，见 `HeroLoop`）。
  - 整页底色是当前精选封面的取色（画面平均色，明度、饱和度封顶，保证白字清楚），横幅下半截先柔化再融进这个颜色；翻过一半时整页颜色用 `Motion.artworkFade`（0.3 秒）过渡。首页内容固定按深色显示，浅色模式下也一样。实现见 `Views/HomeHeroMotion.swift`。
- 首页 · 片库频道：类型 / 地区 / 年份 / 排序四行筛选 + 海报网格；动漫频道是在线动漫的排序 + 网格。
- 首页 · 短剧频道（`DramaTab`）：「短剧 / 漫剧」两个胶囊切换 + 三列 2:3 海报网格（左下角集数角标），滑到底自动翻页、下拉刷新。详情页是封面抬头 + 主按钮（播放第 1 集 / 继续看第 N 集）+ 简介 + 数字选集格子（当前集白底、看过的带光轨进度）。封面是密文，取回后本机解密（`DramaCoverStore`）；播放地址每集现取。只按这两个分类拉列表，站点的换脸类内容不接入。
- 网盘：115 账号卡片、全部文件、传输中心、本机视频。
- 传输中心（网盘 / 我的 → 传输中心）：顶部三格「云端进行中 / 本机下载中 / 边下边播记录」（各带来源色圆点：115 蓝、本机绿、磁力紫）→ 三组入口，每组下面列最多三条进行中任务的光轨进度 → 底部一段说明三种下载的区别。
- 磁力（一级标签）：一条智能输入框（键盘「搜索」键提交；为空时右侧是系统粘贴按钮，不弹粘贴授权，也不主动读剪贴板）。输入框认出磁力链接、40 位 / Base32 信息哈希或迅雷链接时不去站点搜索，下方直接出解析面板（`MagnetLinkPanel`：资源名、短哈希、Tracker 数，「在线播放」「存到 115」「复制」）→ 四等分分类标签「最新 / 专题 / 女优 / 最热」（选中项下方光轨滑条）→ 内容区。
  - 最新：两列 3:4 海报网格，番号浮在封面左上角，下面是两行标题和发行日期，滑到底自动翻页。
  - 专题：五家片商的宽卡片（缩写方块、名称、常见番号前缀、淡淡的名称水印）。
  - 女优：三列圆头像加姓名，按人气排序，滑到底翻页。
  - 最热：顶部一条口径说明（站点没有月榜，取人气女优近 30 天主演新作），下面是带序号的影片行（前三名序号玫红），标出是哪位女优带来的；不翻页。
  - 搜索结果：横向的「匹配女优」卡片 + 「相关影片」影片行。
  - 下钻页（都用 `.hidesTabBar()`，左上角返回上一层）：女优页（头像抬头 + 「主演作品 / 全部参演」切换 + 海报网格）、片商页（片商抬头 + 海报网格）、磁力详情页（封面抬头、参演女优胶囊、磁力资源卡片：中文字幕白底黑字、高清描边，一行「115 云下载播放」主按钮 +「存到 115」+ 复制图标）。「存到 115」统一走 `Offline115Saver`，和离线下载页用同一个保存目录。播放页盖在详情页上，关掉仍停在详情页。
  - 状态统一：加载中用占位块，出错给「重新加载」和「更换镜像域名」，为空用图标加一句话。组件都在 `Views/MagnetBrowseKit.swift`。
- 媒体库管理（我的 → 媒体库管理，全屏二级页）：顶部一张扫描主卡片（进度环、状态、扫描范围、三项进度、主操作与「选择文件夹扫描」）→ 片库概况（匹配进度条 + 片库视频 / 已匹配 / 未匹配）→ 「封面与资料」分组（自动匹配开关、未匹配影片、资料来源、重新匹配）→ 演员资料（开启番号匹配后）→ 「维护」分组（刷新、复制诊断、清空继续观看）。
- 我的：账号卡片、统计 →「我的内容」（我的追番、传输中心）→「播放」（弹幕默认开关）→ 媒体库 / 外观 / 关于。我的追番是三列海报网格，有更新的排前面，长按可取消追番。
- 播放器：竖屏是顶部 16:9 小窗（返回、截图、更多、播放、进度、全屏）+ 下方信息页（片名、清晰度/倍速/字幕/画面/解码快捷格、选集横条、接下来、文件信息）；在线动漫的信息页上方多一行「简介 | 评论」（光轨下划线）和弹幕开关「弹」、弹幕设置；评论页是置顶 / 热评徽章 + 最热 / 最新切换 + 分页加载。弹幕画在视频层上（`DanmakuOverlay`，Canvas 逐帧绘制、带阴影、同速轨道不追尾），横屏控制条倍速键旁也有「弹」开关；区域、不透明度、字号、速度在弹幕设置面板里调。点全屏转横屏，画面铺满，右侧面板分「选集 / 倍速 / 清晰度 / 字幕音轨」四页，选集页带自动连播开关。默认直接横屏播放，点退出全屏键回到竖屏小窗。播放器放在独立的 UIWindow 里（`PlayerWindow`）：主窗口只支持竖屏，播放器窗口才真的横屏，所以控制中心、录屏、系统弹窗方向和旋转锁定都按真实横屏走，其他页面一直是竖屏；关闭时播放页柔和淡出并轻轻缩小后移除窗口，没有翻转，也不用遮罩。所有打开播放器的地方统一用 `.playerWindow(...)`，不要再用 `fullScreenCover`。
- 进入详情、演员合集、网盘目录、设置子页等二级页面时，标签栏自动收起（`.hidesTabBar()`）。

## 新增页面时

1. 用 `DesignPage` / `ScreenTitleBar` / `DesignGroup` / `LibraryActionRow` / `PrimaryActionStyle` 搭，不要自己写背景和字号。
2. 图标只从 `AppIcon` 取；弹层右上角用 `SheetCloseButton`。
3. 列表和网格里的卡片加 `.reveal(index, id: 卡片id)`（一定要带 id），可点的东西加 `.buttonStyle(.pressable)`。
4. 二级页面加 `.hidesTabBar()`；页面根视图加 `.designScreen("名字")`，并在 `docs/prototype-coverage.json` 和 `ScreenCatalogUITests` 里登记。

## 网盘文件管理

- 目录页：面包屑 + 「N 项 · 几个文件夹，几个视频」+ 排序入口（名称 / 大小 / 日期，可反向，文件夹置顶可关）。右上角「⋯」菜单：新建文件夹、选择、排序方式、传输中心、回收站、显示全部文件类型、把此文件夹加入首页、刷新。
- 多选：顶栏「全选 / 全不选」、居中的「已选 N 项」、右侧「完成」；底部浮动操作栏（`FileActionDock`）依次是移动、复制、重命名（仅单选）、信息（仅单选）、下载、加入首页、删除（红色）。选中行底色用 `Theme.tileTint`，行首是 `CheckBadge`。
- 弹层：删除确认用居中卡片（红色图标、被删项目清单、「同时从 HPlayer 资料库移除」开关、红色「移入回收站」主按钮）；移动 / 复制是大号底部面板（移动到 / 复制到分段切换、逐级浏览的文件夹列表、被选中的文件夹灰显并写「已选中，不可作为目标」、底部显示目标位置）；文件信息是带标题、徽章和键值卡片的底部页面。
- 二级页面：回收站（提示条、选中项底部「彻底删除 / 还原」）、离线下载（进行中 / 已完成 / 失败 分段、任务卡片带进度条、速度和剩余时间、底部「清除已完成」「添加任务」）、下载管理（下载中 / 已完成 分段、存储占用卡片、暂停 / 继续 / 重试圆形按钮、已完成显示「播放」或「导出」）。进度条是 6 pt 的光轨渐变，暂停时变灰。
- 危险操作统一用 `DestructiveActionStyle`（红色胶囊 + 白字）；操作进行中用 `OperationOverlay` 挡住重复点击，完成后用底部轻提示。

## 应用图标

- 选择态唯一来源是 `Services/AppIconStore.swift`：点按当帧乐观更新勾选并持久化到 `hplayer.home_icon_choice`；系统 `alternateIconName` 只做延迟校准（切换后 2 秒内不回读覆盖），失败回滚到切换前的选择。不再依赖异步回调或 scenePhase 的即时系统回读，避免「桌面已换、页内勾选不动」。
- 确认提示用页内底部玻璃卡片 `IconChangeNoticeCard`（新图标预览 + 勾选角标 + 「图标已更新 / 主屏幕已同步为…」+ 撤销 + 关闭），4.5 秒自动收起；失败同卡片红色态。不再使用系统 `.alert` 承载成功提示。
- 换图标优先走不弹系统确认框的静默接口（`_setAlternateIconName:completionHandler:`，运行时 `responds(to:)` 校验）；签名不存在时回退公开 `setAlternateIconName`，此时系统仍会弹自己的提示，页内卡片在其后出现。模拟器 `HPLAYER_HOME_TEST=1` 不触碰 SpringBoard，读写 `hplayer.simulated_alternate_icon`。
