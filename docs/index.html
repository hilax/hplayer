安装步骤

  1. 务必用 Safari 打开本页。微信 / QQ / 钉钉内置浏览器不支持安装，点右上角「···」→「在 Safari 中打开」。
  2. 点上面的绿色按钮，弹窗出现后点 「安装」。
  3. 回到主屏幕，等图标进度条走完再打开。
  4. 第一次打开如提示 「未受信任的企业级开发者」：设置 → 通用 → VPN 与设备管理 → 企业级 App 下选中开发者 → 点「信任」。iOS 18 及更新版本显示 「允许并重启」(Allow & Restart)，按提示重启后再打开。
  5. 若提示 「需要开发者模式」：设置 → 隐私与安全性 → 开发者模式 → 打开并重启。

装不上？

  1. 「无法验证 App / Unable to Verify App」：证书已被吊销或过期。联系管理员重新签名上传，装过的人需要删掉旧 App 重装。
  2. 「此 App 无法安装，因为其完整性无法验证」：这台设备的 UDID 不在描述文件里。把 UDID 发给管理员，加入后重签。
  3. 点按钮没反应：确认是 Safari、确认网络能访问 github.io 与 github.com；国内网络可开关飞行模式重试。
  4. 装完立刻闪退：证书被吊销或 profile 与 bundle id 不匹配，让管理员重新签名。
  5. 也可以下载 IPA 后，用全能签 / 轻松签 / Sideloadly 自行签名安装。
