# 首页恢复与 115 全盘扫描

- 启动时从本机 Keychain 恢复保存会话，在首页绘制前恢复当前账号的媒体库和已匹配资料；无需先等待网络验证。
- 首页右上角「更多 → 扫描 115 全盘并匹配封面」从根目录逐页、逐层扫描，只收集视频文件，不下载视频本体。
- 扫描显示已扫描文件夹、发现视频数、匹配状态；支持暂停、继续和重新扫描。退到后台自动保存检查点并暂停，回到前台可从扫描页继续。
- 每个账号独立存储扫描进度与片库，不在扫描记录中保存 Cookie。失败目录保留为未完成，避免误报全盘扫描成功。
- 海报墙只显示已经匹配且有有效远程封面地址的影片；同一部剧合并显示。未匹配文件不删除，在扫描页「管理未匹配影片」可手动匹配或播放，也可继续从资源库访问。
- 「重新自动匹配封面」允许主动重试以前失败的查询，同时保留用户手动校正与取消匹配的决定。封面图片仍需图片服务可用；本次修复不承诺离线图片缓存。
- 扫描页和手动匹配页可选择开启番号匹配，默认关闭。开启后重新尝试未识别的文件，按番号向 R18.dev 查询并核对 `content_id`；同番号的不同命名可复用缓存，不同番号不会因相同标题串用封面。仅发送番号，不发送 115 Cookie、路径或视频内容。关闭后保留已经匹配的结果。

验证覆盖：保存会话和历史账号缓存恢复、资料同步恢复、取消后晚到结果、空封面重试、扫描分页/循环去重/中断续跑、账号隔离、服务端重复或异常分页，以及首页不展示未匹配文件。

设置页另外提供「原生分组 / 分类面板」两套交互原型，用于确认后续设置页布局；原型中的偏好切换、扫描和缓存清理均仅演示，不修改 App 或网盘。
