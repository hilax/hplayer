# iOS 1.3 界面重构

设计依据：[HPlayer 41 屏原型](https://www.figma.com/design/GokGdpKDY5nhYi9YnPRpx9?node-id=4-34)。采用原生 SwiftUI 导航、Tab、表单和媒体图片，不把原型截图嵌进应用，也不把样例影片作为真实片库。

- 首页：500pt 精选、主播放按钮、继续观看、电影、剧集、演员合集；空态仅提供导入与浏览来源。扫描状态、匹配进度、未识别数量移到资源库。
- 资源库：115 账号与容量、磁力、BT 云下载、本机视频、媒体库管理。隐藏尚未实现的 WebDAV/SMB/Emby 占位入口。
- 媒体库管理：复用现有扫描、暂停/恢复、未匹配文件、手动匹配、资料源、演员补全和诊断；资料同步由根页面管理，切换 Tab 后继续生效。
- 设置：账号、独立外观页面、版本与许可；保留已有外观偏好与 Keychain 凭证。
- 详情与搜索：统一留白、海报、标题层级和文件行，电影仍点按播放，剧集按季选集。
- 播放器：中央播放控制与底部进度/设置分离；竖屏设置和选集为底部面板，横屏为侧栏。保留解码、缓冲、手势、字幕音轨、截图与定时关闭。

主题使用统一的背景、表面与主操作色，深浅色均适配；播放页固定深色。新组件集中在 `Views/DesignComponents.swift`。业务服务与播放内核保持现有实现。

验证：本地运行全部视图与 UI 测试文件的 Swift 语法解析和 `git diff --check`；实际 iPhoneOS 编译、单元测试及 iPhone 模拟器播放/页面回归由仓库 `Build unsigned iOS IPA` Actions 工作流执行。最终结果以对应提交的 Actions 记录为准。
